# 🍔 Food Delivery App

React Native (Expo) арқылы жасалған тамақ жеткізу қосымшасы.

## Беттер
- **Кіру (Sign In)**
- **Тіркелу (Sign Up)**
- **Құпиясөзді қалпына келтіру**
- **Верификация** – 4 таңбалы код
- **Басты бет (Home)**
- **Іздеу (Search)**
- **Бургерлер тізімі**

## Қолданылған технологиялар
- React Native
- Expo
- JavaScript

## Іске қосу
```bash
npm install
npx expo start
```
